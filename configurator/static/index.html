Model Settings

Capabilities

What this model accepts. Stored as supports_* keys in the target's extra_body; the switchyard translation layer passes content through by default, so these serve extension policies and documentation. Use the select to leave a capability unset, allow it, or explicitly block it.

Extra request parameters

Merged into every request body sent to this model's provider (e.g. top_k or repetition_penalty for vLLM, service_tier for OpenAI). Permissive backends ignore unknown keys; strict APIs may reject them — only add params the provider understands.
